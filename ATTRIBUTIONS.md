# Attributions

Nnois builds on open linguistic resources and software libraries. This document records their role in the project; consult each upstream project and the copies distributed with this repository for current license terms, notices, and citation guidance.

## Linguistic Resources

| Resource | Role in Nnois | Reference |
| --- | --- | --- |
| Open Multilingual WordNet | Multilingual synsets, lexicalizations, language identifiers, and lexical relations used for cross-language comparison. | [omwn.org](https://omwn.org/) |
| OMW Data | Source data and build utilities used to prepare the multilingual lexical database. | [GitHub repository](https://github.com/omwn/omw-data) |
| Princeton WordNet | English lexical database and synset-relation source for the local WordNet analysis path. | [wordnet.princeton.edu](https://wordnet.princeton.edu/) |

When publishing research based on Nnois results, cite the lexical resources according to their own recommended citation instructions. The `omw-data/` directory contains the source project's citation material where supplied.

### Open Multilingual Wordnet citation

The [OMW Data repository](https://github.com/omwn/omw-data) and its [CITATION.cff](https://github.com/omwn/omw-data/blob/main/CITATION.cff) recommend:

Francis Bond and Ryan Foster. 2013. [Linking and Extending an Open Multilingual Wordnet](https://aclanthology.org/P13-1133/). In *Proceedings of the 51st Annual Meeting of the Association for Computational Linguistics (Volume 1: Long Papers)*, pages 1352–1362, Sofia, Bulgaria. Association for Computational Linguistics.

```bibtex
@inproceedings{bond-foster-2013-linking,
  author = {Bond, Francis and Foster, Ryan},
  title = {Linking and Extending an Open Multilingual Wordnet},
  booktitle = {Proceedings of the 51st Annual Meeting of the Association for Computational Linguistics (Volume 1: Long Papers)},
  year = {2013},
  address = {Sofia, Bulgaria},
  publisher = {Association for Computational Linguistics},
  pages = {1352--1362},
  url = {https://aclanthology.org/P13-1133/}
}
```

OMW also requests citation of the individual wordnets used. Retain their source citation files and distribute the generated `WORDNET_SOURCES.md` with the database.

`omw_multilingual.db` is not an original resource: it is an extraction of the `omw-data/wns/` wordnets, reshaped by [omw-database/create_db.py](omw-database/create_db.py) into a lemma/definition SQLite schema so Nnois can query it efficiently. It is built from over a hundred individually licensed wordnets, each requiring its own attribution. [omw-database/WORDNET_SOURCES.md](omw-database/WORDNET_SOURCES.md) is generated by that same script and lists the name, license, and URL of every wordnet bundled into the database; regenerate it whenever the database is rebuilt and distribute it alongside any copy of `omw_multilingual.db`.

## Scope Of Attribution

Nnois implements the orchestration around these components, including source-language selection, nominal-unit aggregation, contextual scoring, lexical projection, and terminal presentation. The use of an upstream resource or library does not imply endorsement by its maintainers.
